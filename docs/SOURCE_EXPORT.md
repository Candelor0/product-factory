# 源码维护包导出

日期：2026-10-04。对应D-031、FR-010、S4-03和AC-013。本文说明实现协议，实际验收结果见TASKS关联证据。

## 产品入口与内容

当前开发计划的源码区域提供「导出当前源码」。需要有效的确认计划和非空源码；不要求编译或业务验收已通过，因此损坏的代码也可以导出留存。按钮不调用模型，使用原生保存对话框选择新的ZIP文件名。取消不落包；已有文件不覆盖，工作台程序及当前数据目录不能作为导出位置。生成页面和模型没有导出权限，renderer请求也不能指定宿主路径。

包内包含：当前src源码文件；当前确认的需求、页面方向和开发计划JSON；manifest.json；固定编译工具、React运行时、数据与文本AI SDK；真实依赖锁文件；完整性校验脚本、重建脚本和许可说明。包中不读取或复制业务数据库、模型设置/凭据文件、缓存、运行日志、源码历史或已有构建产物。源码、需求文档本身仍是用户内容；用户主动写入其中的私人文字会随源码文档导出，不能把目录排除当作任意内容脱敏。

manifest记录项目、工作台版本、源码版本与哈希、当前确认计划、每个载荷文件的大小和SHA-256。manifest自身不列入自己的哈希清单；这不是数字签名。源码最后提交的实际计划绑定与当前确认计划分别记录，alignedWithCurrentPlan为false时说明代码仍来自旧计划，不能把当前文档和源码同包解释为新需求已经实现。所有导出均明确业务未验收、导出未执行构建；不会修改工作台计划的待办或验收状态。

## 导出过程与保护

主进程先捕获当前源码、确认文档和固定工具，校验随包工具哈希、文本凭据和ZIP条目，再打开保存对话框。对话框返回后，重新核对项目名称、归档状态、确认计划、源码和绑定指纹。期间发生变化时拒绝混合版本导出，原项目和已保存文件保留。主进程互斥锁阻止导出时生成、修改、归档或另一次导出；显式取消及工作台退出会使尚未保存的导出失效。

导出条目限1000个，含ZIP头的总包不超过32MiB。ZIP使用标准store格式和UTF-8文件名，条目只有普通文件，拒绝路径穿越、绝对路径、反斜线、Windows保留名和大小写冲突。源码仍受128文件/单文件128KiB/总2MiB限制。

目标以独占临时文件写入并fsync，重新核验目录身份、文件内容和链接，再通过不可覆盖的发布操作建立最终文件。成功后移除自己的临时文件；故障不覆盖或删除用户已有目标。发布后丢失确认时仅在完整内容哈希、长度和文件身份一致的情况下确认成功，否则返回EXPORT_COMMIT_UNCERTAIN，请保留目标核对。崩溃或外部移动目录可能留下临时文件；没有跨平台dirfd事务，也不声称抵御同一用户任意改写整个文件系统。

## 凭据检查

可信模型服务在内存中检查当前已保存Key是否混入可导出文本，不返回Key给导出器、renderer或模型。检查原文、常见JSON转义、URL编码和base64；另外阻断疑似私钥、token、认证头和明显的硬编码凭据字段。命中时停止导出，不在错误中回显原值，不静默删改源码。无法解密当前已保存Key时不能完成检查，会明确失败；无Key时仍可导出。

该检查是保守的有限模式检查，会有误报，也不能识别所有历史密钥、任意编码或用户自定义秘密。主要边界是只打包明确允许的源码/文档/固定资源，绝不递归打包用户数据根目录。没有将扫描通过表述为“包内绝无任何私人内容”。

## 维护者验证与重建

导出包不包含Node/npm、node_modules、各平台编译器二进制或独立运行服务。维护者自行准备Node 22及npm，按包内README先执行node scripts/verify.mjs，再npm ci --ignore-scripts、npm run build。安装使用固定版本与integrity的真实锁文件，初次可能需要npm仓库网络；业务导出动作本身不联网、不安装依赖。

verify只用Node内置模块，原始包的所有文件按清单检查，缺失、多余、链接及哈希异常均拒绝。依赖安装或源码编辑后，原始包校验不再通过，应保留未修改副本。build允许合法修改src，继续核验固定工具/文档，复用工作台受控虚拟编译器；不执行生成的脚本、配置或后端，也不把语法编译当完整类型或业务检查。

0.13.0固定工具包共16文件；输出dist/app.js、app.css、runtime.js、data.js、ai.js，需要实现相应协议的工作台宿主。包没有start脚本、服务器或导入UI，双击或任意静态服务器不能得到相同运行能力。数据SDK依赖宿主的/app-data及项目会话授权；AI SDK依赖宿主的/app-ai及显式项目授权；包不包含授权记录、额度账本或Key，运行前需宿主重新授权。没有用临时浏览器存储冒充持久数据，也不会自动连回原项目数据。免环境独立启动不属于首版（D-015），源码导入UI尚未实现。0.14.0新增独立的[应用数据备份与恢复](DATA_BACKUP.md)，不会把业务数据混入默认源码包。
