# 工作台视觉与组件规范

日期：2026-10-02。对应 S2-03、NFR-001、AC-020。本文记录本轮已实现方向，供用户审阅；不代表用户已经认可，也不代表完整视觉或可用性验收通过。运行检查与实际截图以本轮证据报告为准。

## 方向与参考

用户反馈当前界面模板感强、信息密度高、缺少产品辨识度。本轮将工作台改为纸白内容区、石灰色导航与墨色文字，以少量砖红表示选中与重点操作位置。通过单一想法入口、侧栏历史与清楚的文字层级组织内容，减少宣传文案、模拟浏览器装饰、重复说明和常驻信息栏。

主代理在线读取了 [Curated Design 的 Desktop Apps 分类](https://curated.design/?category=desktop-apps)，以及该目录收录的 [Harvest 官网](https://www.getharvest.com/) 的真实页面结构与样式。借鉴其克制的导航、暖色中性背景、明确的编辑排版层级与少量暖色强调。此次网站截图工具失败，因此不声称已观察到参考网站截图；未下载或复制其图片、图标、字体、文案或代码。产品实际布局与组件由本项目实现。

0.5.0依据D-023替代0.4.0的项目索引首页。用户提供[界面参考图](references/idea-home-reference.png)，明确中央只保留想法输入、历史集中侧栏，并选择保留浅色。图片中的中央输入结构是参考；截图内的品牌、导出/升级/语音等界面文字不是本项目新增需求。

本轮只改变工作台；固定博客模板与用户生成应用的页面方向是独立设计对象。

## 颜色

样式来源为 [styles.css](../../engineering/desktop/src/renderer/styles.css) 与 [plan.css](../../engineering/desktop/src/renderer/plan.css)。组件优先使用以下语义变量，局部状态色仅在状态需要区分时使用。

| Token | 当前值 | 用途 |
| --- | --- | --- |
| `--ink` | `#24272b` | 正文、标题、主要按钮 |
| `--muted` | `#686962` | 次要文字与说明 |
| `--paper` | `#ffffff` | 内容与表单底色 |
| `--soft` | `#f2f1ec` | 轻量次要区域 |
| `--line` | `#e2e0da` | 分隔线与控件边框 |
| `--accent` | `#b7472d` | 品牌标记、选中下划线、焦点与警示强调 |
| `--accent-soft` | `#f7e9e3` | 错误或待明确内容的浅背景 |
| 导航底色 | `#f5f4f0` | 左侧固定导航 |

颜色不承担唯一状态语义：已确认、失效、运行中、已停止都配有文字。主要操作使用墨色实心按钮；砖红用于有限的选中与提示，避免整页饱和色块。绿色仅用于少量已确认或运行中的辅助状态。

审查后将次要文字加深为 `#686962`，placeholder 调整为 `#74756d`。按实际色值计算，次要文字在白底、浅中性底和浅砖红底的对比分别为 5.55:1、4.91:1、4.68:1；placeholder 在白底为 4.66:1。这些仅是指定颜色组合的数值检查，不代替整页可读性和视觉审阅。

## 字体与间距

采用系统字体栈：`-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、`PingFang SC`、`Hiragino Sans GB`、`sans-serif`。不加载远程字体。0.5.0去掉项目封签和大号项目计数。

| 层级 | 实际基础规格 |
| --- | --- |
| 首页引导 | 32px，字重450，居中；1150px以下29px、880px以下26px |
| 项目名称 | 30px，字重 600，行高 1.45 |
| 页签内容标题 | 20px，字重 600，行高约 1.5 |
| 组标题／项目名 | 14–16px，字重 550–600 |
| 正文／编辑内容 | 14px，行高 1.75–1.85 |
| 控件／说明 | 12–13px；辅助元数据 11px |

内容组通常间隔 24–25px，标签与控件间隔 9px，紧邻操作间隔 8–9px。桌面主内容四周留白为上 48px、左右 56px、下 64px；最大内容宽度 1032px。主要阅读区域不通过缩小字体容纳更多内容。首页另采用视口中央最大780px内容区，只放引导与胶囊输入框；标题与输入间隔34px，输入16px/28px行高、按文字自动增高至220px。

圆角保持节制：普通控件与按钮 5px，图标按钮 4px，对话框 10px。常规内容以细线分隔；阴影仅用于弹窗、操作反馈和极弱的输入区域层次，不把每段内容都放入卡片。

## 页面结构

| 页面 | 首屏主内容 | 渐进展开内容 |
| --- | --- | --- |
| 项目首页 | 一句“你想做一个什么应用？”、一个想法输入框和开始按钮；有无项目一致 | 所有历史/归档项目在侧栏；首页不放列表、计数、面包屑、示例或额外说明 |
| 项目需求 | 项目概述、使用者、功能、页面、版本与保存／确认操作 | 最初的想法；更多需求中的数据、范围、待明确问题与验收 |
| 页面方向 | 方向说明、配色、页面区域清单、版本与确认 | 颜色值、方案说明 |
| 开发计划 | 整理按钮、版本依据、未执行说明、页面和功能清单 | 数据／验收分组，以及规则、来源与记录 |
| 运行样例 | 固定模板说明、运行状态、启停操作 | 不使用大型宣传封面；保存与关闭规则用一段简短说明 |
| 版本记录 | 版本类型、编号、保存时间与确认状态 | 点击版本打开只读历史 |
| 模型设置 | 服务、密钥、调用上限、保存与检测 | 高级连接设置、累计 token／费用信息 |

左侧只保留品牌、项目／归档、新建、项目导航、模型设置与指南。原常驻右栏移除；不显示虚构账户头像。项目阶段放在项目标题附近，用量收进设置，避免相同状态在多处重复。

需求中的问题即使收起，也在表单外显示数量与待明确提醒。开发计划的未解决问题始终显示。折叠只是呈现变化，原始字段、版本与问题不被删除或自动确认。

## 组件和交互

- **按钮**：主要按钮最小高度 38px，13px 字号；紧凑按钮高度 32px。明确区分主要、次要与移除密钥操作。禁用状态保留原有逻辑，不为视觉统一改写条件。
- **首页输入**：Enter开始、Shift+Enter换行；中文输入组合期间不提交。空白禁提交，同一事件轮重复提交仅创建一次。标题取想法前18个Unicode码点并整理空白，可进入项目后重命名。草稿在当前会话的项目切换中保留；成功创建才清空，失败仍保留。输入只创建本地项目，后续模型动作仍需明确发起。
- **输入控件**：1px 边框、5px 圆角、11×12px 内边距。聚焦时使用砖红边框及浅色外环。每个控件有可读标签；placeholder 是示例，不代替标签。
- **页签**：以文字和砖红下划线表示选中，允许换行；保留需求、页面方向、开发计划、运行样例、版本记录入口。
- **折叠区**：使用原生 `details`／`summary`，Tab 可聚焦、Enter 或空格展开。计划默认展开页面和功能，数据与验收默认收起；高级依据默认收起。必须保留内容实际 DOM 与既有测试标识。
- **版本与反馈**：版本编号和已确认／待确认状态可见；需求或方案变化后的旧计划必须显示失效。加载与生成有即时反馈，生成中保留停止入口，错误保留可执行的下一步。
- **弹窗**：普通宽度 490px，设置等宽弹窗 630px；最大高度为窗口减 64px，内部可滚动。Esc 关闭并恢复触发位置焦点。当前焦点循环已包含新增 `summary`、链接等可交互元素，并过滤不可见元素；实际键盘行为另行运行检查。
- **调用边界**：需求／页面生成保留会调用模型与消耗额度的提示；模型设置保留发送内容、密钥保存模式、预算和检测调用的说明。运行样例仍明确是固定模板，不声称自动开发已完成。

## 窗口适配与检查边界

导航默认宽 208px，在 1150px 以下收为 188px，在 880px 以下收为 166px；内容区同步收窄留白。首页不显示顶部栏。项目内容页在880px以下隐藏顶部辅助说明，侧栏保留项目名称。页面结构与需求字段保持两列，页签允许换行。CSS 最小页面宽度为 720px；实际桌面窗口限制与可用性需结合运行证据核对。

应检查 1440／1024px 既定视口，以及实际最小窗口中的滚动、长项目名、折叠内容、弹窗和主要操作。键盘检查覆盖首页单输入、更多需求、计划分组、设置用量和历史方案弹窗。系统启用减少动态效果时缩短动画和过渡。
