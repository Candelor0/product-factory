# 0.5.0 中央想法输入与侧栏项目

2026-10-02，Codex实施，plan_electron负责工作台与视觉回归。对应[D-023](../../../../DECISIONS.md)、FR-003/004、NFR-001、S2-03、AC-004/020。用户提供截图作为结构参考，明确要求首页只有中央想法输入，历史项目集中侧栏，并确认保留浅色。此要求替代0.4.0的项目列表首页；不代表新增聊天、语音或附件功能。

## 实际改动

- 无论是否存在项目，首页均显示一句引导、一个想法输入框和开始按钮；删除中央项目列表、项目计数、顶部面包屑、示例与额外说明。
- 现有项目与归档项目仅在侧栏切换；点击项目进入既有需求工作区，点击“新建项目”直接返回中央输入并聚焦，不再打开创建弹窗。
- 完整想法保存在项目中，默认标题取开头18个Unicode字符并整理空白，后续仍可重命名。当前会话切换项目时保留未提交想法，成功创建后清空。
- Enter提交，Shift+Enter换行；输入法组合事件与keyCode 229不提交。空白不能创建，同轮重复提交由同步防重入保护。
- 创建仅保存本地项目并进入需求页，不自动生成需求或调用模型。已有需求/页面确认、开发计划、运行样例与设置入口保留。

工程变更集中于renderer/App.tsx、styles.css、两份Electron测试、版本信息及打包脚本的已校验缓存入口，内部版本为0.5.0。文档在docs，工程在engineering/desktop，构建与合成测试数据在artifacts；没有将用户运行数据混入工程目录。
