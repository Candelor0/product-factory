# 0.4.0 工作台简化与视觉改版

2026-10-02，Codex实施，ui_simplify_audit负责计划/运行面板与规范审查，plan_electron负责视觉与键盘测试。对应D-022、NFR-001、S2-03、AC-020。用户要求减少AI套版感、降低密度并参考设计网站优化。本轮实现工作台，视觉方向仍待用户审阅。

## 实际改动

- 常驻三栏改为固定左导航与单一内容区；删除右侧重复概况/用量、装饰插画、宣传语、虚构头像和英文栏目口号。
- 有项目的首页改为列表，保留名称、想法、阶段和更新时间；空首页提供单一想法输入及两个简短示例。
- 需求默认显示4个核心编辑字段，4个数据/边界/问题/验收字段保留在原生details内；未明确问题数量在外部提示，保存、确认与未保存保护保留。
- 页面方向改为配色与区域清单；开发计划按任务组折叠；运行样例去掉大型封面；用量与未知费用集中在设置中。
- 统一纸白、灰色与少量砖红，重写主样式，正文不靠缩小字号容纳内容。新增[基础视觉规范](../../../../design/WORKBENCH_VISUAL.md)。
- 修复历史方案弹窗的焦点循环遗漏summary：现在包含链接/summary并过滤不可见控件，恢复触发元素焦点。

工程修改集中于renderer三个组件/两份CSS、工作台及新增视觉测试、package版本/脚本。主进程、存储协议、模型服务与固定博客模板未改。版本为0.4.0，未新增真实模型请求。

## 在线参考

通过ego-browser读取 [Curated Desktop Apps分类](https://curated.design/?category=desktop-apps) 和它收录的 [Harvest官网](https://www.getharvest.com/)。前者用于研究分类、导航和内容分组，后者的实际DOM/样式显示暖色中性背景、墨色标题与较克制的字体层级。参考转化为本工作台的留白、分隔线和有限暖色强调，没有复制网站素材、标识或实现。
