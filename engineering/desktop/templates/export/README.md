# 产品工厂源码维护与重建包

此包保存导出时的源码、项目与确认文档、固定构建工具及依赖锁文件。它用于检查和维护源码；不是免环境独立启动包，也没有 `start`、开发服务器或自动导入工作台的入口。

清单顶层 `binding` 表示导出时的当前确认计划，`source.binding` 表示实际源码检查点的来源；二者可能不同。`source.alignedWithCurrentPlan` 为 `false` 时，这是保留旧来源源码的备份，不表示已经满足新确认需求。导出与重建均不能把业务验收状态改为通过。

## 校验与安装

需要自行安装 Node.js 22 或更新版本与 npm。在尚未安装依赖、构建或编辑的原始解压目录运行：

```sh
node scripts/verify.mjs
npm ci --ignore-scripts
npm run build
```

`verify` 只使用 Node 内置模块，按照 `manifest.json.files` 检查所有载荷文件的字节数和 SHA-256，同时拒绝额外文件、源码、路径穿越、符号链接、硬链接与特殊文件。安装后的 `node_modules`、生成的 `dist` 或任何编辑都会改变原始包，因此完整校验将失败；请保留一份未修改的原始包用于再次核对。校验值证明载荷与清单一致，不是数字签名，不能证明同时被替换的脚本和清单可信。

`npm ci --ignore-scripts` 按真实锁文件安装精确版本，禁止依赖安装脚本。esbuild 的当前操作系统／CPU 对应 optional 原生包必须可用；不要使用 `--omit=optional`。首次安装通常需要 npm 仓库网络；已有完整缓存时可尝试 `npm ci --offline --ignore-scripts`。本包不附带 Node、npm、node_modules 或各平台编译器二进制，也不承诺离线首次安装或所有平台已验收。

## 编辑与重建

默认入口为 `src/app.tsx`，支持受限的 TS/TSX、JS/JSX、CSS、JSON 和源码内相对导入。可导入固定 React 模块及 `@factory/data`、`@factory/ai`，不能引入任意 npm 依赖、Node 模块、动态模块路径、生成构建配置或包管理脚本。构建工具复用工作台实际的 `compileSource`，只解析与转换源码，不在 Node 中执行生成源码。

构建按 `src/` 中的合法文件重新发现和计算快照，允许添加、删除和修改合法源码；不会强制源码仍匹配原始导出哈希，也不会改写原始 `manifest.json`。固定工具、运行资源和文档仍须匹配原清单；源码内链接、非法路径、超限文件和 `src` 外额外源码会被拒绝。源码上限为 128 文件、单文件 128 KiB、总计 2 MiB。每次构建在终端显示本次路径／内容哈希集合的 SHA-256，可用于对比重建输入。

编译通过不代表完整类型检查、业务验收或启动成功。语法失败保留此前构建结果。输出固定为 `dist/app.js`、`dist/app.css`、`dist/runtime.js`、`dist/data.js`、`dist/ai.js`；它们需要适配产品工厂的受限协议宿主，不能通过双击文件或任意静态服务器获得等同的运行与隔离保证。

## 运行与数据边界

可选的 `src/data-schema.json` 声明业务数据结构；没有此文件表示旧版未声明结构。构建会严格校验声明，错误、未知字段或超限会阻断构建，即使入口没有导入该文件。声明最多 64 KiB，版本 1—1000，结构嵌套最多 8 层、256 个 shape 节点；支持 string/number/boolean/null、数组和关闭额外属性的对象，顶层业务键均为可选。对象必须声明 `properties` 与 `required`。

声明可附最多 64 步相邻版本迁移，未声明结构按版本 0：仅支持顶层键改名/新增，以及对象数组中字段改名/补充缺失字段。改名拒绝缺失来源和目标冲突；新增顶层键拒绝覆盖，补充字段保留既有值。迁移不允许任意代码、SQL 或删除步骤。此包的重建只验证声明，不读取真实数据、不执行迁移，也不能据此证明数据兼容；原宿主须独立实现结构绑定、用户影响预览/确认、原子数据提交与回执保护。应用页面不得在启动时自行迁移数据。

React 运行时已作为固定资源附带，不需要安装 React 来构建。`@factory/data` 映射到固定 `data.js`，只请求原协议宿主的 `/app-data` 接口；导出包没有该服务、项目数据、凭据或授权，不会自动访问工作台业务数据。临时预览与持久应用的会话授权、配额和项目范围必须由原协议宿主实现。本版本没有导入 UI，不提供把修改后的 dist 自动装回工作台的能力。

代码和用户数据分别管理。代码重建不读取或修改业务数据；本包默认不包含数据库、凭据、模型原始日志、历史源码或缓存。需要数据备份、迁移或其他运行宿主时，应单独设计并验证授权与兼容性。

第三方许可证见 `LICENSES.md` 和 `licenses/`。导出源码的权利仍归其原有权利人，本工具包不替源码授予第三方内容许可。

`@factory/ai` 映射到固定 `ai.js`，仅向原协议宿主的 `/app-ai` 发送文本请求。导出包不含项目 AI 授权、预算台账、API Key 或模型调用服务。使用者必须由宿主独立实现当前项目/计划授权、供应商连接、预算、去重与撤销；临时预览和启动检查不得调用模型。SDK 不会自动重试，应用须告知输入发送给模型供应商并仅响应用户主动点击。
